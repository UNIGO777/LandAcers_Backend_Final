# LandAcers Portal API 🏢

A robust real estate platform backend built with Node.js and Express, providing comprehensive property management and real estate services.

![API Status](https://img.shields.io/badge/status-active-success)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🌟 Features

- **Property Management** 
  - Property listings with detailed information
  - Multiple property types support
  - Advanced search and filtering
  - Featured properties system

- **Project Management**
  - Real estate project listings
  - Project analytics and tracking
  - Upcoming projects showcase

- **User System**
  - Multi-role authentication (Admin/Seller/User)
  - Profile management
  - Email verification
  - Secure authentication

- **Seller Management**
  - Seller profiles and verification
  - Property posting system
  - Analytics dashboard
  - Performance tracking

## 🚀 Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT
- **Email Service:** Nodemailer
- **File Storage:** Local storage system
- **API Documentation:** Swagger/OpenAPI

## 📋 Prerequisites

- Node.js (v14 or higher)
- MongoDB
- npm or yarn
- Email service credentials
